# Command Palette

## Use when
- Expert or frequent users need fast access across actions and destinations.
- The action set is broad enough that direct search improves efficiency.

## Avoid when
- The palette would hide primary actions that should remain visible.
- Users cannot predict terminology well enough to search.

## Core anatomy
- Invocation shortcut.
- Search input.
- Grouped results.
- Keyboard selection.
- Recent/common actions when useful.

## State and behavior
- No results, loading remote actions, unavailable command, confirmation for dangerous commands.

## Accessibility
- Full keyboard operation is essential.
- Results need clear names and categories.

## Responsive behavior
- Can become a full-screen overlay on small screens.

## Decision rules
- Treat as an accelerator, not a replacement for understandable navigation.
- Use user language and synonyms.
- Dangerous actions still need proportional protection.
